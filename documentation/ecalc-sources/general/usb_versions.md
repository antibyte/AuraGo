# usb_versions — USB versions and speeds / USB-Versionen und Geschwindigkeiten

Kind: transcribed standard (USB-IF specifications and USB-IF naming guidelines)
Guide-value note needed: yes (guide banner; the table quotes USB-IF documents and the specifications by summary)

## Purpose
One row per USB data mode: which specification defines it, the older and the current names (spec name and USB-IF consumer name), signalling rate in total and per lane, lanes, line coding, the connectors that can carry it and the year the defining specification first appeared. Lets a user translate a box label ("USB 10Gbps", "USB 3.1 Gen 2", "SuperSpeed USB") into the real signalling rate and the cable/connector it needs.

## Deliberate deviations
- "USB 1.1 Low Speed" / "USB 1.1 Full Speed" are named "USB Low Speed / Full Speed (USB 1.x and USB 2.0)": both modes were already defined in USB 1.0 (January 15, 1996) and are still part of USB 2.0; the year column therefore shows 1996, the note gives 1.1 = September 1998.
- Added row `g1x2` (USB 3.2 Gen 1x2, 2 × 5 Gbit/s = 10 Gbit/s, Type-C only): the USB 3.2 spec defines it as a separate mode and the USB-IF name "USB 10Gbps" covers both Gen 2x1 and Gen 1x2.
- "USB4 (20 and 40 Gbit/s)" is split into `usb4_20` (Gen 2x2) and `usb4_40` (Gen 3x2) because lane rate and line coding differ. USB4 single-lane links (Gen 2x1 / Gen 3x1, which TI lists) are left out: in the spec they are a link state (fallback), not a product speed with its own name.
- "USB4 Version 2.0 (80 Gbit/s, and the 120 Gbit/s asymmetric mode)" is split into `usb4_80` and `usb4_120`.
- `rate` is the signalling rate of one direction; for `usb4_120` it is the fast direction (the slow direction, 40 Gbit/s, is in the note). The USB4 spec also lists 40/80 and 80/40 Gbps link rates (Table 9-19) for mixed configurations; not separate rows.
- `marketing` shows the current names (Data Performance Guidelines January 2024 and Logo Guidelines January 2026). The "SuperSpeed USB …" names are given in brackets as "formerly": they appear only in the superseded 2018/2019 USB 3.2 guidelines, the current documents no longer list them.
- The research column `check` (cross-check per row) is not a column of the catalog table; its content is the Cross-check section above and the `ref` texts of the vectors. The catalog table also has no `id` column; the key column is `mode`.
- Shipped as `guide: true` (the specifications are authoritative, the table quotes the USB-IF documents and summaries).

## Notes (en / de)
- en: The marketing name tells the signalling rate only. "USB4", "USB 3.2", "SuperSpeed Plus", "Enhanced SuperSpeed" and "SuperSpeed+" are specification terms that USB-IF does not want in product names (Data Performance Guidelines, January 2024).
- de: Der Verbrauchername nennt nur die Signalisierungsrate. „USB4“, „USB 3.2“, „SuperSpeed Plus“, „Enhanced SuperSpeed“ und „SuperSpeed+“ sind Begriffe der Spezifikationen, die das USB-IF nicht in Produktnamen sehen will (Data Performance Guidelines, Januar 2024).
- en: USB Type-C is a connector, not a speed: a Type-C port may carry only USB 2.0 (480 Mbit/s). Modes with two lanes (Gen 1x2, Gen 2x2, USB4) need a full-featured Type-C to Type-C cable.
- de: USB Type-C ist ein Steckverbinder, keine Geschwindigkeit: Ein Type-C-Anschluss kann auch nur USB 2.0 (480 Mbit/s) führen. Modi mit zwei Lanes (Gen 1x2, Gen 2x2, USB4) brauchen ein vollbeschaltetes Kabel Type-C auf Type-C.
