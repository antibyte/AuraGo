# lm1117 — LM1117 low-dropout regulator (TO-220) / LM1117 Low-Drop-Spannungsregler (TO-220)

Kind: authoritative maker document (Texas Instruments)
Pins: 3; types: power 2, signal 1

## Part
LM1117 800 mA low-dropout linear regulator, TI package **NDE, 3-pin TO-220**. TI still lists the TO-220: page 1
"Device Information" names "NDE (TO-220, 3) 14.986 mm × 10.16 mm", section 6 has Figure 6-2 "NDE Package, 3-Pin TO-220
(Top View)", Table 6-1 has a TO-220 column, and the orderable addendum (PDF pages 26–27) shows TO-220 (NDE) parts as
"Active / Production" (e.g. LM1117T-3.3/NOPB, LM1117T-2.5/NOPB, LM1117S-ADJ/NOPB in the tube table on PDF page 33).
Suggested display name `LM1117 (TO-220)`.

Same lead order in TI's other 3-lead packages (Table 6-1): TO-263 (KTT) and TO-252 (NDP) also have ADJ/GND 1, VOUT 2 +
tab, VIN 3; SOT-223 (DCY) has VOUT on 2 and 4 (tab) — see `sot223.md`.

Tab: VOUT (Figure 6-2 prints "VOUT" on the tab; Table 6-1 TO-220 column VOUT "2, TAB").

Suggested item note (en/de): "The metal tab is connected to pin 2 (OUTPUT), as on the LM317: a heat sink on the tab
carries the output voltage. The order is the same as the LM317 (adjust, output, input), not the L78xx (input, ground,
output)." / "Die Metallfahne ist mit Pin 2 (OUTPUT) verbunden, wie beim LM317: Ein Kühlkörper an der Fahne führt die
Ausgangsspannung. Die Reihenfolge entspricht dem LM317 (Einstellung, Ausgang, Eingang), nicht dem L78xx (Eingang,
Masse, Ausgang)."
(The comparison with LM317 and L78xx comes from the existing catalog items `lm317` and `l78xx`.)

## View
Shape `to`, package `to220`: label side towards the viewer, leads down, pins 1, 2, 3 left to right — as `lm317`.
Basis: TI Figure 6-2 "NDE Package, 3-Pin TO-220 (Top View)" draws the part on its side, tab with hole on the left
(labelled VOUT), leads to the right: INPUT at the top, OUTPUT in the middle, ADJ/GND at the bottom. This is the same
drawing style as the LM317 Figure 5-2 used for the `lm317` item. Turning it 90° clockwise (leads down) moves the top
lead to the right: left to right ADJ/GND, OUTPUT, INPUT. TI's figure prints no numbers; Table 6-1's TO-220 column
(ADJ/GND 1, VOUT 2 + TAB, VIN 3) fits that reading. I rendered PDF page 3 to an image and looked at it.

## Cross-check
- Inside TI's document: Figure 6-2 and Table 6-1 agree; Figure 6-1 (SOT-223) and Figure 6-3 (TO-263) on the same page
  show the same INPUT / OUTPUT / ADJ/GND sequence.
- The task's order (ADJ/GND, OUTPUT, INPUT; tab = OUTPUT) is confirmed.
- One maker only: LM1117 is TI's (formerly National's) part; no other maker's LM1117 was read.

## Choices
- Catalog item: names as TI's figure (`ADJ/GND`, `OUTPUT`, `INPUT`) like `lm317`; `ADJ/GND` is `signal` (the function text names both roles). The TO-220 is still listed as active by TI. The SOT-223 version is a variant of the `sot223` examples item.
- Names follow TI's figure (`INPUT`, `OUTPUT`, `ADJ/GND`), like `lm317`; TI's table uses VIN / VOUT.
- `ADJ/GND` typed `signal` (adjust input on the ADJ version); the function text names the ground role of the fixed
  versions. `ground` would suit only the fixed versions.
- Item id `lm1117` collides by name with the `lm1117` variant suggested inside the `sot223` examples item; they are
  in different scopes (item vs. variant), but the catalog author may want `lm1117_to220` or a distinct variant id.
