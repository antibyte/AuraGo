# mcp23017 — MCP23017 16-bit I2C I/O expander (DIP-28) / MCP23017 16-Bit-I2C-Portexpander (DIP-28)

Kind: authoritative maker document (Microchip, the only maker; no second maker exists for this part number). Part: MCP23017 16-bit I/O expander with I2C interface, in the 28-pin SPDIP (300 mil), 28 pins. Microchip's Table 2-1 gives one pin-number column for "SOIC, SPDIP, SSOP" and one drawing for those three packages. The MCP23S17 of the same document (SPI version) uses the same package positions for the ports and supplies but different functions on pins 11 to 14 (CS, SCK, SI, SO), so it is NOT a drop-in for the I2C part.
Pins: 28; types: power 1, ground 1, signal 6, data 2, io 16, nc 2

## Pins
Names are Microchip's (Table 2-1 and the MCP23017 drawing in "Package Types"). Table 2-1 is shared with the MCP23S17 and writes the shared pins as `NC/CS`, `SDA/SI` and `NC/SO`; the MCP23017 drawing labels them `NC`, `SDA` and `NC`, which is what the names below use. Overbars could not be seen (see View); `RESET` is active low per the timing table, and its function text says so.

## View
Shape `dip`, 28 pins: package from above, pin 1 top left, numbers counter-clockwise. Basis: the "Package Types" box on page 1 has an MCP23017 drawing labelled "SOIC", "SPDIP" and "SSOP" with a dot at pin 1, 1–14 down the left (GPB0 … GPB7, VDD, VSS, NC, SCK, SDA, NC) and 28–15 down the right (GPA7 … GPA0, INTA, INTB, RESET, A2, A1, A0). Caveat: this PDF is encrypted (AES-256) and the Windows PDF renderer used for the other records could not open it, so I did NOT look at the drawing as an image; I read its text layer with `pdftotext -layout`, which keeps each label next to its pin number. The drawing's notch/dot and any "Top View" caption were not seen, and overbars on pin names cannot be seen in a text layer. The text-layer order (1–14 down the left, 28–15 down the right) matches Table 2-1 pin by pin.

## Cross-check
One maker document is enough: Microchip is the only maker of the MCP23017. Inside the document, the MCP23017 drawing (text layer) and Table 2-1 (column "SOIC, SPDIP, SSOP") agree on all 28 pins. No disagreement in numbers.

Differences inside the document, names only:
- Pins 11, 13 and 14: Table 2-1 `NC/CS`, `SDA/SI`, `NC/SO` (shared with MCP23S17); the MCP23017 drawing `NC`, `SDA`, `NC`.
- Pin 12: Table 2-1 and the drawing say `SCK`; the functional block diagram labels the I2C clock "SCL". The name follows the table.

## Choices
- Catalog item: GPA7 and GPB7 stay `io` and say "output only (datasheet revision D)" in the function text (older revisions listed them as I/O, the pin note says so); pins 11 and 14 are `NC` as the MCP23017 drawing labels them (Table 2-1 shares them with the SPI part); `RESET` drops its overbar and says "active low"; the item notes state that the drawing was read from the text layer only.
- Port pins `io`, like the `atmega328p` item. GPA7 and GPB7 stay `io` with "output only" in the function: Revision D changed them (Features: "Pins GPA7, GPB7 are output only for MCP23017"; Table 2-1 adds "Output only (MCP23017)"; Revision History D: "Updated Table 2-1", "Updated drawings for MCP23017", "Updated Section 3.5.1"). Older revisions and many tutorials show them as normal I/O; the note warns about that. An `io` type with this text seemed less misleading than `signal`.
- `SCK` and `SDA` are `data` (I2C bus pins). `A0`–`A2`, `RESET`, `INTA`, `INTB` are `signal` (control). Pins 11 and 14 are `nc` on the MCP23017.
- `RESET` active low: Table 1-2 parameter 30 "RESET Pulse Width (Low)" and parameter 34 "Output High-Impedance From RESET Low"; Table 2-1 "Hardware reset. Must be externally biased." The overbar itself was not seen (text layer). "Tie high for normal operation" follows from active low plus "must be externally biased"; Microchip does not say "tie to VDD" in the pages read.
- Supply: Table 1-1 D001 1.8 V to 5.5 V. The Features list also gives 4.5 V to 5.5 V for −40 °C to +125 °C. The pin text uses 1.8 V to 5.5 V.
- No I2C pull-up statement was found in the pages read for SDA/SCK, so none is in the record.
- The QFN package (EP pad 29, different numbering) is left out.
