# bt136 — BT136 triac (TO-220) / BT136 Triac (TO-220)

Kind: authoritative maker document (WeEn Semiconductors, the successor of NXP's/Philips' thyristor line)
Pins: 3; types: signal 3 (see Choices)

## Part
BT136-600, 600 V / 4 A four-quadrant triac in SOT78 (TO-220AB). Suggested display name `BT136 (TO-220)`.
WeEn's product page lists the BT136-600 as "Volume production"; datasheet Rev.02 of 25 September 2024.

Not this pinout:
- **BT136X-600** (isolated TO-220F full pack): a search summary of WeEn's BT136X sheet says the mounting base is
  "n.c." and isolated — not read, but it shows the "X" type differs at the tab. The item must say "not for BT136X".

## Choices
- Catalog item: names `T1`, `T2`, `G` as WeEn; "MT1/MT2" in the function so a search finds them; all three `signal` (load terminals are not a supply rail). The note says the isolated BT136X is not covered; that statement rests on a search summary only and is a warning, not data. One maker only (WeEn, the successor of NXP's line).
- Names follow WeEn (`T1`, `T2`, `G`); "MT1/MT2" go into the function text so that a search for them finds the pin.
- Type `signal` for all three, as for the transistors in `to92`. T1 and T2 carry the load current (often mains); `power`
  would also be defensible for them, but they are not a supply rail.
