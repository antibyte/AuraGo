# sn74hc595 — SN74HC595 shift register (DIP-16) / SN74HC595 Schieberegister (DIP-16)

Kind: authoritative maker document
Pins: 16; types: power 1, ground 1, signal 2, data 12

## View
Shape `dip`, 16 pins: package from above, notch at the top, pin 1 top left, numbers counter-clockwise. Basis: TI's section 5 figure is captioned "D, N, NS, J, DB, or PW Package", "16-Pin SOIC, PDIP, SO, CDIP, SSOP, or TSSOP" and "Top View". It shows the notch on top, 1–8 down the left, 16–9 down the right. I rendered PDF page 3 to an image and looked at it.

## Cross-check
One maker document is enough here. Figure and Table 5-1 agree on 15 pins.

Disagreement inside the datasheet: Table 5-1 has no 16-pin number for VCC. Its VCC row shows a dash in the SOIC/PDIP column and 20 in the LCCC column. The figure of the 16-pin packages shows VCC at pin 16. I chose pin 16: the figure is explicit, and 16 is the only number the table leaves unused. The table's dash looks like an editing error. The same table also gives RCLK and SRCLK the same LCCC number (14), which does not touch this item. I report the VCC gap in case a reader compares the table.

Nothing UNVERIFIED.

## Choices
- `OE` and `SRCLR` carry an overbar at TI, which plain text cannot show. Names stay `OE` and `SRCLR`, so that a search finds them, and the function text says active low.
- Types as planned: SER, SRCLK, RCLK and all Q outputs `data`; OE and SRCLR `signal`.
- `QH'` keeps TI's apostrophe and is quoted in the YAML.
- The 20-pin FK package is left out.
