# cd4511 — CD4511B BCD-to-7-segment latch/decoder/driver (DIP-16) / CD4511B BCD-zu-7-Segment-Latch, -Decoder und -Treiber (DIP-16)

Kind: authoritative maker documents (primary Texas Instruments, cross-check onsemi)
Pins: 16; types: power 1, ground 1, signal 10, data 4

## Part
CD4511BE: CMOS BCD-to-7-segment latch, decoder and driver with lamp test, blanking and latch enable, in the 16-pin plastic DIP (TI: "16-lead dual-in-line plastic packages (E suffix)"). Its outputs are high-active and source current (TI: "up to 25 mA") for common-cathode LED displays. Suggested display name `CD4511B (DIP-16)`, the same in all locales.

Members that share this pinout, as far as a datasheet says so:
- CD4511B in the ceramic DIP (F3A), SO (NSR) and TSSOP (PW, PWR): TI's sheet shows one terminal assignment for the CD4511B and lists these packages.
- onsemi MC14511B: same function at every pin in its "PIN ASSIGNMENT". TI's page 1 says "These devices are similar to the type MC14511"; neither document says "pin-for-pin" in so many words.
- Renesas CD4511BMS: no document found (the Renesas URL pattern that served the other CD4000 parts answered HTTP 404), so not claimed.

Suggested item note (TI truth table on PDF page 4 and page 1; onsemi page 2 for the last sentence): the BCD inputs are scattered: A (lowest bit) is pin 7, B pin 1, C pin 2, D pin 6. The segment outputs a to g are on pins 13, 12, 11, 10, 9, 15 and 14. With ~LT and ~BL high and LE low, the code on D C B A shows as a digit; codes above 9 blank the display. ~LT low lights every segment, ~BL low blanks the display, and LE high holds the last code. ## View
Shape `dip`, 16 pins: package from above, notch at the top, pin 1 top left, numbers counter-clockwise. Basis: TI's page 1 (sheet 3-255) has the drawing captioned "TOP VIEW", "CD4511B TERMINAL ASSIGNMENT". It shows the notch on top, a dot at pin 1, 1–8 down the left (B, C, LT, BL, LE/STROBE, D, A, VSS) and 16–9 down the right (VDD, f, g, a, b, c, d, e), with overbars on LT, BL and STROBE. TI's sheet is a scan of the Harris data sheet: I rendered page 1 at six times the base resolution, enlarged the terminal assignment and the functional diagram and read each label; the logic diagram and truth table on PDF page 4 were read at three times. onsemi's "PIN ASSIGNMENT" (page 2) draws the package upright with a dot at pin 1 and the same labels in vector text.

## Cross-check
Both sources agree pin by pin on all 16 pins: B 1, C 2, lamp test 3, blanking 4, latch enable 5, D 6, A 7, VSS 8, segments e 9, d 10, c 11, b 12, a 13, g 14, f 15, VDD 16. Inside TI's sheet the terminal assignment and the functional diagram (A 7, B 1, C 2, D 6, LE/STROBE 5, LT 3, BL 4, a 13 … g 14, "VSS = 8", "VDD = 16") agree. The two truth tables agree row by row: LT low gives all segments 1 (display 8); BI low with LT high gives all 0 (blank); with LE low the code D C B A from 0000 to 1001 gives the digits 0 to 9 and 1010 to 1111 give blank; LE high keeps the code "previously applied when LE = 0". The weights follow from the tables: 0001 shows 1, 0010 shows 2, 0100 shows 4 and 1000 shows 8; onsemi page 1 calls the decoder "8421 BCD-to-seven segment".

Differences, none of them in the pin numbers:
- Pin 4: TI's terminal assignment and functional diagram print `BL` with an overbar, its page 1 text says "Blanking (BL)", but its own truth table heads the column `BI` with an overbar; onsemi prints `BI` throughout.
- Pin 5: TI `LE/STROBE` with the overbar over STROBE only; onsemi `LE`.
- Packages: onsemi lists SOIC-16 and SO-16 WB, no DIP. TI's sheet is the only one that names the plastic DIP.
- Supply: recommended 3 V to 18 V in both. Absolute maximum: TI −0.5 V to +20 V; onsemi −0.5 V to +18.0 V.

## Choices
- Names follow TI's terminal assignment, the primary source.
- Overbars: TI prints overbars on LT, BL and on STROBE in `LE/STROBE`. This record writes `~LT`, `~BL` and `LE/~STROBE` (the `~` sits where the bar starts). If the catalog strips overbars as in the shipped `sn74hc138` item, write `LT`, `BL` and `LE/STROBE` (or onsemi's plain `LE`); the function text already gives the polarity. No name collision arises.
- `~BL` is kept from TI's drawing although TI's truth table and onsemi say `BI`; both mean the blanking input on pin 4.
- Segment output names stay lower case `a` to `g`, as both makers print them; the catalog allows names of 1 to 24 characters.
- Types: A to D are `data` (TI "BCD INPUTS", stored in the input latch, like the data lines of the shipped register items); LT, BL and LE are `signal`; the segment outputs are `signal` because they drive display segments, not a data bus. Typing A to D `signal`, like the select inputs of the shipped `sn74hc138` item, would also be defensible.
- Pin 16 text uses the recommended range 3 V to 18 V of TI and onsemi, not TI's 20 V absolute maximum.
- "An output that is high must not be shorted to VSS" rests on onsemi page 2 ("damage can occur to the device if VDD is applied, and the outputs are shorted to VSS and are at a logical 1"); "common-cathode LED displays" and "up to 25 mA" on TI page 1 (features and applications) and onsemi page 1.
- No current-limiting resistor value is given in either document, so none is stated.
- Catalog names: `~LT`, `~BL` and `LE/~STROBE` become `LT`, `BL` and `LE/STROBE` with "active low" in the function text. Pin 4 stays `BL` (TI's pin figure); onsemi and TI's truth table call it `BI`, and the item note says so.
