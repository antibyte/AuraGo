# sot223 — SOT-223 examples (3 leads + tab) / SOT-223: Beispiele (3 Anschlüsse + Fahne)

Kind: authoritative maker documents (LM1117: Texas Instruments only; BCP56: onsemi primary, Diodes Incorporated cross-check)
Pins: 4 per variant (3 leads + tab = pin 4), 2 variants; types: lm1117: power 3, signal 1; bcp56: signal 4

## Package
SOT-223: three leads along one long side, a wide tab on the opposite side. Both makers read here number the tab as
pin 4: TI Table 6-1 gives VOUT on SOT-223 as "2, 4"; onsemi's BCP56 symbol says "COLLECTOR 2,4". The tab is always
connected to the same node as the middle lead (pin 2) in both examples — this is a property of these parts, not of
the package.
Suggested item: an "examples" item, shape `to`, package `sot223`, `pins: ["1", "2", "3", "4"]` (the tab is the last
entry, as `internal/ecalc/pinouts.go` requires). Suggested name `SOT-223: examples` / `SOT-223: Beispiele`.

## View
Shape `to`, package `sot223`: seen from above (marking side up), pins 1, 2, 3 along the bottom from left to right, the
tab = pin 4 at the top (`internal/ecalc/pinouts.go`). Basis, figures rendered and looked at:
- **onsemi BCP56 "MARKING DIAGRAM"** (page 1; marking text visible, so seen from above): tab at the top, three leads at
  the bottom, "1" at the lower-left lead. Same orientation as the catalog view; no mapping.
- **TI Figure 6-1 "DCY Package, 4-Pin SOT (Top View)"**: drawn on its side, tab on the left ("Tab is VOUT"), leads to the
  right: INPUT at the top, OUTPUT in the middle, ADJ/GND at the bottom. Turning it 90° clockwise (leads down) moves the
  tab to the top and the top lead to the right: left to right ADJ/GND, OUTPUT, INPUT. TI's figure has no pin numbers;
  Table 6-1 (SOT-223 column) gives ADJ/GND 1, VIN 3, VOUT 2 and 4, which fits that reading.
- **Diodes "Top View Pin-Out"** (BCP54/55/56, page 1): drawn on its side the same way, tab "C" on the left, leads to the
  right: E at the top, C in the middle, B at the bottom. Turned 90° clockwise: left to right B, C, E; tab C at the top.
  This agrees with onsemi's numbers 1 B, 2 C, 3 E, 4 C.

## Members that share this pinout
- lm1117: the AMS1117 (Advanced Monolithic Systems, "1A LOW DROPOUT VOLTAGE REGULATOR", http://www.advanced-monolithic.com/pdf/ds1117.pdf, read pages 1, 5 and 7 on 2026-11-27) prints under "3 PIN FIXED/ADJUSTABLE VERSION" and "SOT-223 Top View": 1 Ground/Adjust, 2 VOUT, 3 VIN, the same as leads 1 to 3 of the `lm1117` variant. What the SOT-223 tab is connected to is NOT stated there: "TAB IS OUTPUT" is printed only next to the TO-252 drawing, and the SOT-223 drawings label no tab. The item's note therefore says so and asks to check the tab on the part; the `lm1117` variant's tab (pin 4, output) rests on TI only. The AMS1117 8-lead SOIC is numbered differently and is not covered.

## Cross-check
- bcp56: onsemi (numbers + names) and Diodes (names at positions, side view turned) agree pin by pin: B 1, C 2, E 3,
  tab C. No difference.
- lm1117: one maker only. TI's figure and TI's table agree with each other (and the TO-220 figure on the same page has
  the same lead order, which supports the reading of the rotation). LM1117 is a TI (formerly National) part; no second
  maker's LM1117 was read. Similar parts from other makers (e.g. ST LD1117, AMS1117) are different products and were
  not used.
- Package numbering: onsemi's marking diagram puts pin 1 at the lower left with the tab on top; TI numbers the tab 4,
  onsemi "2,4" — the tab is pin 4 in both.

## Choices
- Catalog item: examples item `sot223` (name translated in all 16 locales like `to92`) with the variants `lm1117` (a variant id may equal an item id) and `bcp56`; pin 4 is the tab, named like pin 2 and typed like it. The LM1117 rests on TI only; the BCP56 on onsemi with Diodes as the cross-check.
- Pin names for the LM1117 follow TI's figure (`INPUT`, `OUTPUT`, `ADJ/GND`), as the `lm317` item does; TI's table
  writes VIN and VOUT.
- `ADJ/GND` typed `signal` because on the adjustable LM1117 it is the adjust input; on the fixed versions it is ground.
  Typing it `ground` would suit the fixed versions only. The function text names both roles.
- The tab is a separate pin entry "4" with the same name as pin 2, as the shape needs four entries.
- BCP56 pins `signal`, like the transistors in `to92`.
