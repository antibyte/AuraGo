# lm741 — LM741 operational amplifier (DIP-8) / LM741 Operationsverstärker (DIP-8)

Kind: authoritative maker documents (primary Texas Instruments, cross-check STMicroelectronics UA741)
Pins: 8; types: power 2, signal 5, nc 1

## Part
LM741 in the 8-pin plastic DIP (TI "NAB Package, 8-Pin CDIP or PDIP"; the hobby part is usually the LM741CN). One general-purpose op amp with two offset-null pins and one unconnected pin. Display name `LM741 (DIP-8)`, the same in all locales.

Members that share this pinout, as far as a datasheet says so:
- LM741, LM741A and LM741C in CDIP and PDIP: TI's NAB figure and the Pin Functions table cover the whole sheet ("The LM741C is identical to the LM741 and LM741A except" for the temperature range).
- ST UA741 (UA741C and UA741I) in DIP8 (N) and SO-8 (D): same function at every pin.
- Not this pinout: the LM741H in the 8-pin TO-99 metal can (LMC package), which has the same numbers but a round layout; not part of this `dip` item.
- Not claimed: the UA709, although ST page 1 says "Same pin configuration as the UA709"; no UA709 datasheet read.

## View
Shape `dip`, 8 pins: package from above, notch at the top, pin 1 top left, numbers counter-clockwise. Basis: TI's figure "NAB Package, 8-Pin CDIP or PDIP, Top View" (section 5, page 3) shows a notch at the top, 1–4 down the left (OFFSET NULL, INVERTING INPUT, NON-INVERTING INPUT, V−) and 8–5 down the right (NC, V+, OUTPUT, OFFSET NULL). ST's "Pin connections (top view)" on page 1 draws the same package with a notch at the top, the amplifier symbol inside (− input to pin 2, + input to pin 3, output to pin 6) and the pin list below. I rendered TI PDF page 3 and ST PDF page 1 to images and looked at both figures.

## Cross-check
Both sources agree on the function of every pin: offset null 1 and 5, inverting input 2, non-inverting input 3, negative supply 4, output 6, positive supply 7, no connection 8. Inside TI's document the NAB figure and the Pin Functions table agree on all 8 pins; the TO-99 figure uses the same numbers.

Differences, none of them in the pin numbers:
- Names: TI writes both offset pins as "OFFSET NULL"; ST numbers them "Offset null 1" (pin 1) and "Offset null 2" (pin 5). TI writes the supplies V− and V+, ST VCC− and VCC+. TI writes "NC", ST "N.C.".
- Supply: TI gives a split supply (±10 V to ±22 V, LM741C ±18 V); ST gives 5 V to 40 V total.

## Choices
- Names follow TI, the primary source, except that the two "OFFSET NULL" pins get ST's numbers (`OFFSET NULL 1` on pin 1, `OFFSET NULL 2` on pin 5) so that no two pins share a name.
- `V-` is written with an ASCII hyphen, as the shipped `lm358` item writes `V-`.
- Types: inputs, output and offset-null pins `signal`; both supplies `power` (as `lm358` types its V− pin, because the LM741 normally runs from a split supply and pin 4 is not ground); pin 8 `nc`.
- The supply range goes into the note, not into the pin texts, because it differs between LM741/LM741A and LM741C.
- How to wire the offset trim (a potentiometer between pins 1 and 5) is not given in either document read, so the note does not describe it.
