# lm393 — LM393 dual comparator (DIP-8) / LM393 Doppelkomparator (DIP-8)

Kind: authoritative maker document, cross-checked against a second maker. Part: LM393 dual differential comparator in the 8-pin PDIP (TI package P), 8 pins. Pin-compatible relative read in the same documents: LM2903 (TI lists "LM293, LM393, LM393A, LM2903" under PDIP (8) and draws one figure for all of them; onsemi's sheet also covers LM2903 with the same pin drawing).
Pins: 8; types: power 1, ground 1, signal 6

## Choices
- Catalog item: names are TI's (`1OUT`, `1IN-` ... `VCC`); the pull-up note sits on pins 1 and 7; the item notes carry the output-short warning, the AND remark and the split-supply remark on GND; the supply pin says only "Positive supply" because the makers' ranges differ.
- Names follow TI (`1OUT`, `1IN-`, `1IN+`, `2IN+`, `2IN-`, `2OUT`), the same style as the existing `lm324` item.
- `GND` is typed `ground`: TI names the pin GND and describes it as "Ground". This differs from the `lm358` item, where TI's name is V– and the type is `power`. onsemi's feature list mentions split supplies (±1.0 Vdc to ±18 Vdc); in that use pin 4 is the negative rail. A note could say so; the name stays GND.
- Function text says inverting / non-inverting input, the wording of the existing op-amp items. TI's table says "Negative input pin" and "Positive input pin".
- Open collector, read in TI: section 6.1 says the open-collector outputs allow level shifting to a logic level independent of VCC and an AND function when several outputs are tied together; section 6.3 says the output is a pull-down NPN transistor that sinks current when the negative input is higher than the positive input; section 6.4.1 says the output is "logic low or high impedance (logic high with pullup)". So a pull-up resistor is needed for a high level, and the output is low when IN− is above IN+.
- Supply range, read in TI section 5.2: 2 V to 30 V for the non-V, non-B devices, which include the plain LM393 (V devices 2 V to 32 V, B versions 2 V to 36 V). onsemi's sheet states 2.0 Vdc to 36 Vdc for its parts. Because the makers differ, the pin function says only "Positive supply"; if a range is wanted, TI's 2 V to 30 V is the narrower one.
- TI's absolute maximum table (page 4) carries the note that a short from an output to VCC can cause excessive heating and eventual destruction. Worth a line in the item notes.
- Left out: the WSON (DSG) package with thermal pad of Figure 4-2, and the SOT-23 package; both have their own drawings.
