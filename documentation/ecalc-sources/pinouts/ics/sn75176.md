# sn75176 — SN75176B differential bus transceiver, RS-485 (DIP-8) / SN75176B Differenzial-Bus-Transceiver, RS-485 (DIP-8)

Kind: authoritative maker documents, one maker only (Texas Instruments, the maker of the part). TI's SN75176B datasheet was read; no second maker document that names the SN75176 could be read (see UNVERIFIED). Inside TI the pinout is confirmed by three drawings and by TI's separate SN75176A datasheet, which has the same pinout.
Pins: 8; types: power 1, ground 1, data 4, signal 2

## Part
SN75176BP: one RS-485/RS-422 transceiver (3-state differential line driver plus differential line receiver, single 5 V supply) in the 8-pin plastic DIP (TI package P, "PDIP, 8"). Display name `SN75176B (DIP-8)`, the same in all locales.

Members that share this pinout, as far as a datasheet says so:
- SN75176B and SN65176B in SOIC (D), PDIP (P) and SOP (PS): one SLLS101I datasheet, Package Information lists "SNx5176" in all three, one pin figure (Figure 4-1, "Top View").
- SN75176A (TI SLLS100C): its own "D OR P PACKAGE (TOP VIEW)" figure and Table 5-1 have the same name and function at every pin. The SN75176A is the slower part (TI: "Low Speed RS485 communication (5 Mbps or less)", "For 10 Mbps, use SN75176B").
- NOT claimed: MAX485 (Maxim 19-0122 Rev 8, read from SparkFun's copy) and LTC485 (Linear Technology Rev M, read from Digi-Key's copy). Neither document read says it is pin compatible with the SN75176; the current LTC485 sheet names only the LTC2862 as pin compatible. A search snippet quotes an older LTC485 revision as "Pin Compatible with the SN75176A, DS75176A and µA96176", but that revision was not opened.

## View
Shape `dip`, 8 pins: package from above, notch at the top, pin 1 top left, numbers counter-clockwise. Basis: TI SLLS101I Figure 4-1 "Top View" (section 4, page 3) shows a notch at the top, R, RE, DE, D on pins 1–4 down the left and VCC, B, A, GND on pins 8–5 down the right. The figure carries no package caption; the Package Information table on page 1 lists D (SOIC 8), P (PDIP 8) and PS (SOP 8) for the whole sheet. TI's SN75176A figure is captioned "D OR P PACKAGE (TOP VIEW)" and draws the same layout. I rendered SLLS101I pages 1, 3 and 4 and SLLS100C page 3 to images and looked at the figures.

## Cross-check
Inside SLLS101I, Figure 4-1, Table 4-1 and the simplified schematic on page 1 agree on all 8 pins (R 1, RE 2, DE 3, D 4, GND 5, A 6, B 7, VCC 8). TI's SN75176A sheet gives the same name and function at every pin. No second maker's document naming the SN75176 was read, so there is no maker-to-maker cross-check.

For information only, not used as a source of this item: Maxim's MAX481/MAX483/MAX485 sheet (19-0122 Rev 8, 10/03) names the same signals RO, RE, DE, DI, GND, A, B, VCC; its pin figure was not compared pin by pin, and the sheet does not claim SN75176 compatibility.

## Choices
- Names follow TI (`R`, `RE`, `DE`, `D`, `GND`, `A`, `B`, `VCC`); the overbar on `RE` is dropped as in the shipped `sn74hc595` item (`OE`, `SRCLR`), and "active low" is in the function.
- Types: R, D, A and B carry the data, so `data` (as the shipped `max232` item types its UART-side and RS-232-side pins); the two enables `signal` (as `OE` in `sn74hc595`); GND `ground`; VCC `power`. Alternative: A and B as `io`, since they are bidirectional (TI type "I/O"); I chose `data` to match `max232`.
- Pin 8 text uses TI's recommended 4.75 V to 5.25 V (5.2), not the 7 V absolute maximum.
- "to the UART (RX)" / "from the UART (TX)" in the R and D texts is an explanation of TI's "Logic data output from RS-485 Receiver" / "Logic data input to RS-485 driver"; the words RX and TX are not in TI's table.
