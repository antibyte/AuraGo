# ne555 — NE555 timer (DIP-8) / NE555 Timer (DIP-8)

Kind: authoritative maker document
Pins: 8; types: power 1, ground 1, signal 6

## View
Shape `dip`, 8 pins: package from above, notch at the top, pin 1 top left, numbers counter-clockwise. Basis: the TI figure is captioned for the NE555 "D, P, PS, OR PW PACKAGE" and "(TOP VIEW)", and shows the notch on top, 1–4 down the left and 8–5 down the right. I rendered PDF page 3 to an image and looked at the figure.

## Sources
1. Texas Instruments, NA555, NE555, SA555, SE555 xx555 Precision Timers, SLFS022K (Sept. 1973, revised March 2026), section 4, figure and Table 4-1. https://www.ti.com/lit/ds/symlink/ne555.pdf — covers the NE555 in P (PDIP), read PDF page 3, accessed 2026-11-04.

## Cross-check
One maker document is enough here. Figure and Table 4-1 agree on all 8 pins. No disagreement, nothing UNVERIFIED.

## Choices
- Name uses `DIP-8`, the same in all 16 locales: it holds only a proper name and a package name, so there is nothing to translate.
- `RESET` is written without its overbar. TI's table does not use one for this pin; the function text says active low.
- All timer pins, `OUT` included, are `signal` as planned.
- The 4.5 V to 16 V range of pin 8 is TI's table description; the SE555's 18 V is left out because this item is the NE555.
- The 20-pin FK package of the SE555 (with NC pins) is left out.
