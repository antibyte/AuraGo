# usb_b — USB 2.0 Type-B / USB 2.0 Type-B

Kind: free official specification
Pins: 4; types: power 1, ground 1, data 2

## View
Written for the receptacle, looking at its mating face (`drawn: socket`): upper row 2 1, lower row 3 4, chamfered corners at the top.

Basis: the text layer of the interface drawings, read by position. Figure 6-8 ("USB Series "B" Receptacle Interface") has `2 1` above `3 4`. Figure 6-10 (Series B plug, "Section A - A") has `1 2` above `4 3`. These are mirror images of each other, as the catalog schema's other view expects. I rendered the same receptacle sheet from ECN #1 (page 18) and looked at it: the shell is chamfered at the top.
