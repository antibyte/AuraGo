# AuraGolf MIDI source files

These original MIDI files are retained for reproducible conversion by
`scripts/build-minigolf-music.mjs`. Each source is released as CC0 on
OpenGameArt.org; attribution and the exact download URL are also recorded in
`ui/3d/minigolf/music/manifest.json` alongside the SHA-256 of these bytes.
