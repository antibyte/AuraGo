# Maritime and isometric authoring

Original MIT assets, authored using Blender 5.2.1 LTS. The authoritative motif
lists are `catalog.py`: 120 maritime motifs in three representations and 240
isometric entries. Editable compressed `.blend` files remain in `production/`.
Only GLBs, PNG/WEBP previews, manifests and licenses are runtime data.

Production order (from repository root, using the installed Blender executable):

1. Run Blender headless with `--python assets/game-maker-worlds/build.py`.
2. Run `render_review.py` to inspect the exported GLBs, not the authoring meshes.
3. Run `render_sprites.py` for the native-resolution maritime frames.
4. Run `build_isometric.py`, then `render_sprites.py -- --source
   assets/game-maker-worlds/production/isometric-glb --views isometric`.
5. Run `python assets/game-maker-worlds/pack_sprites.py --view top`, then `side`
   and `isometric`. Packing quantizes colors without dithering and adds a
   one-pixel silhouette outline; it never resizes individual animation frames.
6. Run `python assets/game-maker-worlds/verify.py`. Reports and contact sheets go
   under ignored `reports/game-maker-worlds/`, not the delivered resources.

Do not run integrity/import tests while a production command is replacing its
output. These source builds are offline operations; project imports remain
transactional. Per-pack uncompressed caps are 48/20/16/40 MiB, with 4 MiB reserved
for additional shared runtime helpers. Frame counts are not motif counts.

`GAMEMAKER_WORLD_BROWSER=1 go test ./internal/gamemaker -run
'TestWorld(PackExportBrowser|IsometricExportBrowser|MaritimeReferences)'` exercises
real published ZIPs on a static server under a subpath. Optional environment
`GAMEMAKER_WORLD_REPORTS` retains screenshots, observations and the four maritime
reference exports. Tests use normal Chrome keyboard input, real contacts and
projectile crossings. They never assign the win state to manufacture evidence.

The reference sources use the same local asset helpers and one engine loop.
Their deterministic, small maps isolate loading, directional animation,
contacts, victory, restart and disposal. They are technical reference games,
not finished commercial game designs. The isometric reference is generated by
`world_isometric_browser_test.go`, using the real plan/template/compiler path.

Manifest `production_status: review` means that production output is awaiting
the full visual, performance and agent acceptance ledger. A successful parser
or smoke test does not establish that acceptance.
