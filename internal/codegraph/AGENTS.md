# Native code graph

- Keep this package CGO-free. Import only the pinned language-specific
  gotreesitter grammars; do not link its complete grammar registry.
- `Project` is an internal capability resolved by the server. Never accept an
  arbitrary host root from a tool or HTTP argument. Revocation applies before
  scans, publication and query return. Root substitution cannot reuse an ID.
- Publish coherent snapshots only. A failed/partial file has no published facts;
  expose skipped coverage and freshness. Unresolved edges never prove safety.
- Keep source/index in RAM, one cancellable parser worker, bounded regular-file
  reads and conservative index accounting. No process execution or refactoring.
- `documentation/learnings.md` owns user guidance. Tests include all six source
  extensions, aliases, local bindings, changes/deletions and lifecycle boundaries.
